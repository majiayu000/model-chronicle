# 时间轴聚焦：A + B

状态：用户已授权 A + B；2026-09-28 增补同代规格折叠与厂商聚焦。

## 行为

1. 时间轴默认“最近 12 个月”，边界从今天回退 12 个日历月，包含两端；闰日回退到目标月末。仍以 GA 优先、缺失时用宣布日期。只有月份精度的记录与窗口相交即保留，不伪造日精度。
2. “全部历史”恢复所有符合筛选的模型。数据、下载、搜索、详情和其他分析视图保留完整目录。
3. 最近窗口只展开有窗口内模型的产品线。每条线的“前 N 代”展开符合筛选的早期模型，显示日期和详情链接；历史条带放在该行下方，不改变其他行的时间坐标。完整的几何时间轴可用“全部历史”查看。
4. 窗口外模型组按厂商折叠，展开后展示日期和模型链接。“窗口外”只表示此窗口没有收录新发布，不宣称官方停更或弃用。
5. 同厂商、同系列、同代际且相互没有祖先/后代关系的型号优先合为一个规格组，可以跨档位。Gemma 4 的 31B、26B MoE、E2B、E4B 和 12B 合为一个可展开的组；各规格保留独立详情、原始日期和档位。组内日期不同时显示日期范围，不伪装为同日发布。同代的连续修订版不按并行规格合并。其余既无前代也无后继的独立模型仍按厂商、档位并列；筛选后只剩一个节点的真实继任线不能当作独立模型。规格组与独立型号不生成继任连线。
6. 时间轴统计卡片、覆盖计数和热图跟随窗口及当前筛选。厂商筛选计数使用窗口及档位/能力条件；展开历史不会改变窗口统计。页面说明统计口径并保留全库总量。其他视图延续全库统计。
7. 时间窗口、规格展开、历史展开和厂商归档写入分享链接。刷新、复制链接、返回/前进保持状态；无参数链接使用最近窗口，非法参数忽略。切换窗口重置横向滚动。
8. 最近窗口的默认缩放随屏幕宽度调整（220–840 px/年），窄屏仍支持时间轴内部横向滚动；手动缩放后固定所选值并写入链接。
9. 时间窗口栏右侧提供厂商单选与“恢复全部”，厂商分组标题旁提供“只看这家”。两个入口都只修改厂商条件，保留时间窗口、档位和能力筛选。现有厂商标签继续支持多选，下拉框同步显示“已选 N 家（多选）”或“未选择厂商”。厂商条件沿用 `vendors` 分享参数。
