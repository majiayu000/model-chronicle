# 系列时间轴与个人显示设置

状态：2026-09-28，按用户确认的“系列 → 版本 → 型号”设计实现；用户已授权提交、发布。

## 信息层级

1. 每个厂商下按产品系列占一行，同一系列的节点保持在同一水平线上。单一型号点击直接打开详情；包含多个型号的版本点击后在时间轴内展开树形子节点，以分支线连接版本与型号，不再在行下方显示型号列表，不生成重复的 1/1 面板。档位作为型号属性，不再决定行数。
2. OpenAI 的 `gpt` 与 `gpt-pro` 在展示上合为 GPT 系列；`o-series` 与 `o-series-pro` 合为 o 系列；gpt-oss 单独保留。GPT-5.4 的主型号、mini、nano、Pro 放在同一个 5.4 节点内；Astra、Sol、Luna 放在 6 节点内。
3. GPT 版本从已有型号名称提取显示标识，保留 Turbo、4o 的区别，避免历史 `generation` 中的 mini 后缀将规格误拆成版本。其他系列沿用已有 generation。同版本中的前后继修订记录按在该版本内的继任深度分开，附原始日期，不将连续修订混成并行规格。
4. 系列内版本节点保留继任连线：仅在两个可见型号之间存在原始 predecessor 关系时连接它们所属的版本。同一版本对的多条型号关系合并成一条线，悬停列出具体型号和各自间隔；仅在间隔相同且空间足够时在线上标注。并列规格不互相连线；隐藏、筛掉或移出窗口的中间型号不会触发跨级补接。原始 predecessor、详情中的继任线和数据导出不变。
5. 节点使用符合当前日期/厂商/档位/能力条件的最早型号定位；隐藏该型号不移动同版本的时间位置。恢复 Dense 圆点、MoE 菱形、未公开架构的空心圆、推理外圈和仅宣布虚线标记。多个型号的架构或推理状态不一致时使用中性标记，避免把整个组误标成某一种架构。节点不再上下错层；密集处仅错开文字与隐藏控件，保留真实横向时间位置。连续继任主线水平连接，跨过其他可见版本的真实分支单独画弧线。

## 时间窗口与筛选

- 默认最近 12 个日历月，包含边界，闰日回退至目标月末。月份精度记录与窗口相交即保留。日期口径仍为 GA 优先、缺失时用宣布日期。
- “全部历史”展示全部未隐藏且符合筛选的记录。系列的“早期 N 个型号”与厂商的“窗口外系列”保留历史入口。
- 时间窗口栏右侧可单选厂商和恢复全部，厂商标题旁可“只看这家”。现有标签保留多选。厂商切换不清空档位、能力、时间范围。
- 卡片与覆盖率使用当前可见型号；热图展示时间范围涉及的完整自然年，截至当前月份，仍跟随厂商、档位、能力与隐藏筛选，计数独立于时间轴；范围内原始数量与隐藏数量在工具栏明确列出。全库收录总数不受个人隐藏影响。
- 默认缩放适配屏宽；手动缩放、时间窗口、厂商、版本展开、历史与归档展开可随链接保存。旧版本组链接与原产品线根节点链接迁移到新结构。

## 隐藏、撤销和恢复

- 具体型号名称左侧的眼睛按钮隐藏单个型号；版本节点左侧隐藏这个版本的全部已收录型号；系列名称左侧隐藏整个系列的全部已收录型号，包含当前筛选未显示的早期型号。
- 隐藏按实际型号 ID 保存，仅影响本机浏览器的时间轴。搜索、详情、比较、其他分析视图与 JSON/CSV 不受影响；隐藏列表不进入分享链接。
- 隐藏后显示可见/隐藏计数和带“撤销”的提示。撤销只恢复这一步新隐藏的 ID，保留此前单独隐藏的记录。手动恢复后清理旧撤销状态，避免误恢复其他项。
- “已隐藏”面板列出所有本机隐藏项，可逐个恢复或全部恢复。全部隐藏后，恢复入口仍可见。
- 使用版本化 localStorage 记录，刷新保留。未知 ID、重复 ID 与损坏记录安全退回；读写被浏览器拒绝时保留本次操作，并明确说明刷新后可能恢复。
- 系列/版本隐藏保存的是当时已收录 ID，今后新增型号默认可见。没有服务端账户同步，也不将偏好上传。
