# 时间轴聚焦：A + B

状态：用户已授权 A + B；2026-09-27 实现并验证。

## 行为

1. 时间轴默认“最近 12 个月”，边界从今天回退 12 个日历月，包含两端；闰日回退到目标月末。仍以 GA 优先、缺失时用宣布日期。只有月份精度的记录与窗口相交即保留，不伪造日精度。
2. “全部历史”恢复所有符合筛选的模型。数据、下载、搜索、详情和其他分析视图保留完整目录。
3. 最近窗口只展开有窗口内模型的产品线。每条线的“前 N 代”展开符合筛选的早期模型，显示日期和详情链接；历史条带放在该行下方，不改变其他行的时间坐标。完整的几何时间轴可用“全部历史”查看。
4. 窗口外产品线按厂商折叠，展开后展示这些线的日期和模型链接。“窗口外”只表示此窗口没有收录新发布，不宣称官方停更或弃用。
5. B 只将原始目录中既无前代也无后继的独立模型按厂商、档位合并展示。窗口内和窗口外分别分组；筛选后只剩一个节点的真实继任线不能当作独立模型。独立型号不画继任连线或等待下一代的虚线；同日或近邻节点错开垂直位置，保证均可点击和键盘访问。
6. 时间轴统计卡片、覆盖计数和热图跟随窗口及当前筛选。厂商筛选计数使用窗口及档位/能力条件；展开历史不会改变窗口统计。页面说明统计口径并保留全库总量。其他视图延续全库统计。
7. 时间窗口、展开的产品线和厂商归档写入分享链接。刷新、复制链接、返回/前进保持状态；无参数链接使用最近窗口，非法参数忽略。切换窗口重置横向滚动。
8. 最近窗口的默认缩放随屏幕宽度调整（220–840 px/年），窄屏仍支持时间轴内部横向滚动；手动缩放后固定所选值并写入链接。

## 验收

- 不改 YAML 或导出数据，不生成任何新的 predecessor。
- 固定日期验证窗口边界、闰年、月份精度、空结果、旧线展开和完整历史覆盖。
- 验证独立模型分组不会跨厂商/档位、不会连接无继任关系节点、同日型号不会覆盖点击区域。
- 路由往返测试覆盖窗口、历史展开、非法值和刷新默认值。
- 构建、现有与新增测试、格式检查通过；浏览器验证最近/全部、逐行历史、厂商归档、筛选统计、详情返回、手机布局与控制台。

## 保留边界

“仍是当前代”只是当前已收录继任链的末端，不表示厂商仍在售或它仍是主力；本次不改变生命周期语义。最近窗口随日期移动，分享链接保留窗口选择，不固定某次统计快照。
